# ระบบเปิดซุ้มการ์ดสุ่มไอเท็ม (Gacha Card System)

โปรเจกต์นี้เป็นระบบสุ่มกาชาแบบ "เปิดซุ้มการ์ดทีละใบ" สำหรับเว็บเกม เช่น FiveM หรือเกมแนว RPG โดยจำลองความรู้สึกการเปิดกล่อง เปิดการ์ด หรือสุ่มของแรร์แบบเกมจริงๆ!

## ฟีเจอร์

- ระบบสุ่มไอเท็มตามระดับความหายาก (Rarity)
- แสดงผลการเปิดการ์ดด้วยภาพแบบเท่ๆ
- รองรับเสียงประกอบตอนเปิดการ์ด (เพิ่มอรรถรส!)
- โค้ดเขียนด้วย HTML + CSS + JavaScript พร้อมนำไปต่อยอด

## ระดับความหายากของไอเท็ม

- **Standard**  
- **Heroic**  
- **Epic**  
- **Limited**  
- **Legend**  
- **Ultimate**  
- **Mythical** *(หายากสุด ได้จากกิจกรรมพิเศษเท่านั้น)*
